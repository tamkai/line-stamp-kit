# LINE Stamp Kit

Claude Code / Codex で、**計画をつくる → スタンプにする** の二段階で LINE スタンプ一式を作るキット。

自分の写真や手描きキャラを 1 枚置いて話しかけると、表情とひとことの一覧（計画）が出てきます。
そこを直してから、透過 PNG を生成し、検収して、LINE Creators Market に申請できる zip まで仕上げます。

## 何ができるか

- **個数を選べる**: 8 / 16 / 24 / 32 / 40 個（LINE の規格どおり）
- **絵柄を見て選べる**: 極太線ゆるカワ / 厚塗りポップ / 線なしフラット / 線画×水彩 / ゆる手描き / クレイ風の 6 種を、同じマスコットで並べたギャラリーから選ぶ。自分で足すこともできる
- **本物の透過 PNG**: 背景を切り抜くのではなく、アルファチャンネル付きで直接生成する。エッジが綺麗
- **同じキャラで揃う**: 参照画像と「お手本 1 枚」を毎回添付して、顔・線・白フチを揃える
- **検収ページ**: ブラウザで一覧を見て、作り直したい番号にチェック → 文をコピーして伝えるだけ
- **申請規格へ自動変換**: 370×320 以内・メイン 240×240・タブ 96×74・余白・偶数・1MB 以下・zip

できあがるもの: `output/stamps_submit.zip`（`01.png`〜`NN.png` + `main.png` + `tab.png`）

## 必要なもの

- **Claude Code** または **Codex CLI**（どちらでも動く）
- **Codex CLI の有料プラン**（Plus 以上）。画像生成は Codex 組み込みの機能を使うので、**OpenAI の API キーやクレジット購入は要りません**
- **Python 3**（画像の検査と規格変換に使う。Pillow は自動で入る）

不足していれば `stamp-setup` が自動で確認・案内します。

## 入れ方

**Claude Code と Codex のどちらでも使えます。** 同じリポジトリで両対応しています。

### Claude Code の場合

```
/plugin marketplace add tamkai/line-stamp-kit
/plugin install line-stamp-kit@line-stamp-kit
```

画像生成には Codex CLI が入っていてログイン済みである必要があります（`codex login`）。

### Codex の場合

```bash
codex plugin marketplace add tamkai/line-stamp-kit --ref main
codex plugin add line-stamp-kit@line-stamp-kit
```

## 使い方

1. 作業用のフォルダを作り、元にしたい画像を `reference.png`（jpg 可）として置く
2. エージェントにこう話す:

```
LINEスタンプを作りたい            ← 用途・個数・表情・絵柄を聞かれる。計画（stamp_plan.json）が出てくる。ここで直す
これをスタンプにして              ← 自分の写真で試し打ち（選んだ絵柄だけ / 全絵柄で見比べ）→ 残りを生成 → 検収ページ → 申請用 zip
```

作り直しは、検収ページ（`output/review.html`）で番号にチェックを入れて、右下の文をコピーして貼るだけです。

うまく動かないときは「スタンプの準備を確認して」と言うと、環境を診断して直します。

## 中身

| スキル | 役割 |
|---|---|
| `stamp-plan` | 第 1 段階。用途 → 個数 → 表情とひとこと → 絵柄 → メイン番号を決めて `stamp_plan.json` で止める |
| `stamp-make` | 第 2 段階。メイン 1 枚を試作 → 全数を並列生成 → 検収 → 作り直し → 規格変換・zip |
| `stamp-setup` | 環境の準備・診断。画像生成で **本物の透過 PNG** が出るかを 1 枚試して機械検査する。通常は自動で走る |

### 仕組み（気になる人向け）

- 画像生成は **Codex 組み込みの image_gen**。Claude Code から使うときは、1 枚ごとに
  `codex exec --ephemeral` で使い捨ての Codex を起動する（画像がセッションログに溜まらない）
- Codex 単体で動かすときは、Codex 自身が image_gen を呼ぶ。Python のスクリプト群は共通
- 生成後に Pillow で「RGBA か」「透過率」「四隅が透明か」「見切れ」「隣の番号と同じ絵か（取り違え）」を機械検査する
- 絵柄は `skills/stamp-plan/styles/*.txt` の 1 ファイル。作業フォルダに `style.txt` を置くと差し替えられる

## 注意

- **実在の人物**を元にするときは本人の許可を。有名人や他人のキャラ・版権物は申請できません
- 画像 1 枚に 2〜5 分かかります。8 個で 40〜60 分（作り直し込み）が目安
- **Codex の使用量は大きい**です。画像 1 枚で Plus の 5 時間枠の約 2%（実測）。8 個セットで約 25%、16 個で約 45%。24 個以上は 5 時間枠をまたいで分けるか Pro プランが必要です。始める前に ChatGPT の「プランの利用上限」で残量を確認してください
- 申請後は個数を変えられません。計画の段階で決めてください
