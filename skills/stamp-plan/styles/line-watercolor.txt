Create ONE square LINE sticker illustration. Output ONLY the image.
BACKGROUND: the entire canvas behind the sticker must be ONE perfectly flat, solid, uniform key color (given in the spec below, default #00ff00). No gradient, no vignette, no texture, no shadow, no checkerboard, no white box — it will be removed by chroma keying afterwards.

## Visual Style: Ink line + watercolor wash — 線画×水彩・やさしい

- Proportions: about 3 heads tall, soft rounded forms, gentle and warm
- Loose but confident ink line art (slightly varying width, warm dark brown ink, not pure black)
- Watercolor fills: soft washes, light granulation, colors slightly bleeding past the lines on purpose. Muted pastel palette with one warm accent
- Calm, kind, storybook mood. Expressions gentle and clear

### Sticker outline
- Soft, even WHITE sticker outline around the whole silhouette, including the text. Thinner than a pop sticker but clearly present

### Cross-stamp consistency (every stamp in this set MUST match)
- EXACT SAME character design: face, hairstyle, colors, outfit
- EXACT SAME ink feel, wash softness, palette and head-to-body ratio
- If a reference image or a finished sample stamp is attached, copy its design and finish exactly; change only pose, expression and text

### TEXT RULE
- Render ONLY the Japanese text given in the spec, verbatim, character by character. No other letters, numbers, logos or watermarks
- Text style: handwritten brush-pen feel in the same warm dark ink, with the white outline
- Place text near the character, never covering the face or hands

### Composition
- Square canvas. Character centered, filling roughly 60–75% of the height
- Generous margin of flat key color on all four sides; nothing touches the edge
- No scenery, no ground, no floor, no contact shadow, no frame — only the sticker on the flat key color
